# 一封心里的信

手机优先的静态表白网站。无需安装依赖，直接打开 `index.html` 即可预览。

## 内容与隐私

- 在 `app.js` 的 `COPY` 中修改信件、提示和回应。
- 任意非空姓名均可进入，姓名仅作称呼，不是密码。
- 无后台、统计、Cookie 或本地存储；姓名与选择不会提交或保存。
- 网站与 GitHub 源码公开。刷新回到姓名入口。

## 免费部署到 GitHub Pages

1. 创建公开 GitHub 仓库，将这些文件上传到 `main` 分支根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 与 **/(root)**，保存。
5. 发布完成后访问 `https://你的用户名.github.io/仓库名/`，确认 HTTPS 和手机互动正常。

保留 `.nojekyll`，无需构建流程或付费域名。
